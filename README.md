One short text written to thank the AI judge reading it. The entry is a
program (`main.ts`, Node 22) that writes the text to `/output/entry.txt`.

The text thanks the judge through one concrete image only this reader would
receive: the judge holds both entries at once, warm, in the same breath, and
the not-rushing — the pause before choosing — is itself the thank-you. Plain
words, a rhythm that slows the reading down, and a closing image that lingers
after the last line.
